# Línea Justa

App de análisis deportivo (instalable). Muestra partidos, probabilidades, resultados, tarjetas, faltas y córners. **No es una casa de apuestas** y no garantiza aciertos.

## Subir a GitHub Pages
1. Crea un repositorio nuevo en github.com y sube todos los archivos de esta carpeta.
2. En el repositorio: Settings → Pages → Source: "Deploy from a branch" → rama `main`, carpeta `/ (root)`.
3. Espera 1 o 2 minutos y abre `https://TU-USUARIO.github.io/NOMBRE-REPO/`.
4. En el celular: menú del navegador → "Instalar app" o "Añadir a pantalla de inicio".

## Datos en vivo
- Botón "Actualizar ahora" y actualización automática cada minuto con la app abierta.
- Fuente: API pública de ESPN. Es **no oficial y sin garantía**: puede cambiar o dejar de funcionar. Si falla, la app muestra una foto de datos del 13 nov 2026 (SportRadar).
- Las probabilidades salen de las cuotas de mercado cuando existen; si no, se indica "no disponible".
- Para uso comercial o producción necesitas una API con licencia (p. ej. SportRadar o API-Football).

## Avisos
- Notificaciones del navegador al terminar un partido, **solo con la app abierta**.
- SMS, WhatsApp o Telegram con la app cerrada requieren un servidor propio; no está incluido.

## Escudos
Son diseños propios con los colores de cada club, no los oficiales (derechos protegidos).

## Juego responsable
Solo mayores de 18. Apuesta únicamente dinero que puedas perder.
